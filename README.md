# GANN Player (DJPlayer) для macOS

Плеер с плейлистами, waveform и диджейскими эффектами перехода (crossfade и high-cut filter).

## Возможности

**Треки**
- Список треков в плейлисте, воспроизведение по `Пробел`, остановка по `Esc`
- Двойной клик по треку — запуск, правый клик — контекстное меню
- При запуске нового трека текущий останавливается (или переходит по эффекту)
- Изменение порядка треков перетаскиванием, удаление по `Delete` в списке
- Треки с исчезнувшими файлами помечаются значком предупреждения

**Восстановление пропавших файлов**
- Если файл трека исчез с прежнего места, плеер ищет его копию на диске в фоне
- Кандидат принимается только при совпадении **SHA-256 содержимого** — имя и размер недостаточны
- Найденный файл подставляется вместо пропавшего: идентификатор трека прежний, поэтому цвет, точки обрезки, флаги и позиция в списке сохраняются
- Такой трек помечается значком **©** вместо ноты: файл тот же самый, но лежит не там, куда его указывали
- Хэши считаются заранее, пока файлы на месте: у удалённого файла хэш уже не посчитать. Первый запуск после обновления досчитывает их в фоне
- Треки, пропавшие **до** обновления, восстановить автоматически нельзя — хэша для них нет. Такой трек остаётся с предупреждением: файл нужно добавить или перепривязать вручную
- Файл, переименованный после пропажи, не находится: поиск идёт по имени. Это ограничение `mdfind`

**Плейлисты (левая колонка)**
- Создание, переименование, удаление
- Изменение порядка перетаскиванием
- Цвет выделения для каждого плейлиста (10 цветов палитры)
- Экспорт плейлиста в файл `.djplaylist.json` (кнопка «Сохранить») и импорт (кнопка «Загрузить»)

**Сохранение**
- Все плейлисты, треки, выбранный плейлист и настройки эффектов автоматически пишутся при любом изменении и при выходе
- Файл состояния: `~/Library/Application Support/DJPlayer/appstate.json`
- Файл содержит `schemaVersion`. Состояние предыдущих версий (без этого поля) читается и мигрирует молча — плейлисты не теряются
- Если файл состояния повреждён, он сохраняется рядом как `appstate.corrupt-<дата>.json`, а в окне показывается сообщение с именем копии

**Waveform**
- Верхняя полоса окна всегда зарезервирована под waveform: пустое состояние — той же высоты
- Пики считаются в фоне, не блокируют интерфейс
- Индикатор прогресса и курсор воспроизведения, цвет — цвет выбранного плейлиста
- Перетаскиваемые маркеры Start Time / End Time (Audio Trim)

**Эффекты (правый верхний угол окна)**
- **Crossfade** — плавный переход, регулятор длительности 0.5–15 с
- **High-cut** — «уводит» верхи у играющего трека фильтром низких частот (как ручка фильтра на DJ-контроллере), регулятор длительности 0.3–10 с. **Следующий трек запускается только после полного завершения эффекта.**
- **Focus Fade** — плавная пауза при переходе в другую программу и плавное возобновление при возврате
- Оба переключателя перехода независимы. Если включены одновременно, при смене трека приоритет у High-cut.

**Ошибки**
- Проблемы с файлом, сбой движка и повреждённое состояние показываются в окне, а не только в консоли

## Требования

- macOS 14.0 (Sonoma) или новее — значение задано в `Package.swift` и в `Resources/Info.plist`, они обязаны совпадать
- Swift 6.0 toolchain (Xcode 16) — только для компиляции; языковой режим проекта остаётся Swift 5

## Структура проекта

```
DJPlayer/
├── Package.swift                         # манифест SwiftPM: DJPlayer, DJPlayerCore, тесты
├── Sources/
│   ├── DJPlayerCore/                     # модуль без AppKit/SwiftUI — покрыт юнит-тестами
│   │   ├── Models.swift                  # Track, Playlist, RGBAColor, AppSettings, AppState, PlaylistFile
│   │   └── StorageManager.swift          # чтение/запись состояния, резервные копии, экспорт/импорт

│       ├── AudioEngine.swift             # два канала, crossfade, high-cut, отсчёт времени
│       ├── FileRelinker.swift           # поиск пропавшего файла по индексу и сверка SHA-256
│       ├── WaveformGenerator.swift       # расчёт пиков waveform и длительности
│       ├── WaveformView.swift            # отрисовка waveform
│       ├── PlaylistSidebar.swift         # левая колонка
│       ├── TrackList.swift               # список треков
│       ├── ContentView.swift             # главное окно и элементы управления
│       └── Theme.swift                   # хелперы цвета и формата времени
├── Tests/DJPlayerCoreTests/              # формат файла, миграция, хранилище
├── Resources/
│   ├── Info.plist                        # единственный источник настроек бандла
│   ├── DJPlayer.entitlements             # права для подписи
│   └── AppIcon.icns
└── .github/workflows/build.yml           # тесты → сборка → .app
```

## Компиляция через GitHub

### 1. Создайте репозиторий

Загрузите содержимое папки `DJPlayer` в корень репозитория: `Package.swift` и `Sources` должны лежать прямо там, без вложенной папки.

### 2. Загрузите файлы

Можно перетащить через веб-интерфейс GitHub. Файлы `.github/workflows/build.yml` и `Resources/` тоже нужны.

### 3. Дождитесь сборки

Вкладка **Actions** → запустится workflow **Build DJPlayer**. Сначала прогоняются тесты, потом собирается универсальный бинарник (arm64 + x86_64). Занимает обычно 3–8 минут.

### 4. Скачайте приложение

В завершённом запуске, внизу страницы, раздел **Artifacts** → скачайте `GANN-Player-macOS` (это `GANN Player.app.zip`).

### 5. Первый запуск

Без секретов подписи приложение подписывается ad-hoc, поэтому macOS его заблокирует. Варианты:

- Правый клик по `GANN Player.app` → **Открыть** → **Открыть** в диалоге
- Либо снимите карантин: `xattr -dr com.apple.quarantine "/Applications/GANN Player.app"`
- Либо **Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть»**

### Подпись и нотаризация (необязательно)

Без секретов приложение подписывается ad-hoc и при первом запуске требует обхода Gatekeeper (см. выше). Чтобы этого не требовалось, задайте в **Settings → Secrets and variables → Actions**:

| Секрет | Что это |
|---|---|
| `BUILD_CERTIFICATE_BASE64` | сертификат Developer ID Application в `.p12`, закодированный в base64: `base64 -i cert.p12 \| pbcopy` |
| `P12_PASSWORD` | пароль от этого `.p12` |
| `DEVELOPER_ID_APPLICATION` | имя сертификата, ровно как в `security find-identity -v -p codesigning`, например `Developer ID Application: Иван Иванов (TEAM123456)` |
| `APPLE_ID` | Apple ID разработчика |
| `APPLE_TEAM_ID` | Team ID (10 символов) |
| `APPLE_APP_PASSWORD` | app-specific password с appleid.apple.com — **не** обычный пароль |

Если заданы все шесть, workflow подпишет приложение с hardened runtime и entitlements, отправит на нотаризацию через `notarytool`, прикрепит тикет через `stapler` и проверит результат `spctl`. Приложение будет запускаться двойным кликом без предупреждений, в том числе офлайн.

Если заданы только первые три — приложение будет подписано Developer ID, но не нотаризовано: Gatekeeper всё ещё покажет предупреждение, зато подпись будет валидной.

`--deep` при подписи намеренно не используется: он устарел и подписывает вложенный код неверно. Вложенный бинарник подписывается отдельно, до бандла.

### Перенос настроек между версиями

Файл состояния читается и старым, и новым приложением: миграция выполняется при загрузке. Специальных действий не требуется.

## Локальная сборка

```bash
cd DJPlayer
swift test                       # только модуль ядра, GUI не нужен
swift build -c release
.build/release/DJPlayer
```

Собрать `.app` вручную:

```bash
mkdir -p DJPlayer.app/Contents/MacOS DJPlayer.app/Contents/Resources
cp .build/release/DJPlayer DJPlayer.app/Contents/MacOS/
cp Resources/Info.plist DJPlayer.app/Contents/Info.plist
cp Resources/AppIcon.icns DJPlayer.app/Contents/Resources/
printf 'APPL????' > DJPlayer.app/Contents/PkgInfo
codesign --force --sign - --entitlements Resources/DJPlayer.entitlements DJPlayer.app
open DJPlayer.app
```

## Использование

| Действие | Как |
|---|---|
| Играть / пауза | `Пробел` |
| Остановить | `Esc` |
| Запустить конкретный трек | Двойной клик по треку |
| Добавить треки | Кнопка «Добавить» над списком или перетащить файлы из Finder |
| Создать плейлист | `+` в шапке левой колонки |
| Переименовать / цвет / удалить плейлист | Меню `⋯`, появляется при наведении |
| Изменить порядок | Перетаскивание в списке |
| Сохранить плейлист в файл | «Сохранить» внизу левой колонки |
| Загрузить плейлист из файла | «Загрузить» внизу левой колонки |

## Если сборка упала

Смотрите **Actions → упавший запуск → шаг Test** (или **Build**) — там будет точная ошибка компилятора с номером строки.

Частые причины:
- `Package.swift` не в корне репозитория
- Файлы лежат во вложенной папке (`DJPlayer/DJPlayer/Sources`)
- Тест упал после изменения формата файла состояния — значит, старые файлы перестали читаться; это блокирующая ошибка, а не мелочь
